# PROJECT: RentalHub – Equipment Rental Platform

## Description
RentalHub is a web-based equipment rental platform connecting customers with equipment owners and
rental businesses. Users browse equipment, check availability, compare rental options, book for
specific dates, track rental and return status, and leave reviews. Owners manage listings, pricing,
availability, and bookings. Administrators manage users, equipment, categories, and platform activity.

## Expected Solutions
1. Comprehensive digital lifecycle: discovery → booking → pickup → tracking → return, with precise records
   (no spreadsheets, fewer booking conflicts).
2. Three roles with clear accountability: Owners (list assets, dynamic pricing, monitor utilization),
   Customers (compare options, real-time availability, manage rental schedule),
   Administrators (oversight, quality control, dispute resolution).
3. Centralized booking and availability engine with a real-time calendar: once booked, equipment is
   instantly unavailable for those dates platform-wide.
4. Business analytics via MongoDB aggregation: revenue trends and utilization to maximize asset ROI.

## Core Requirements: Authentication, CRUD, Booking System, File Uploads, MongoDB Aggregation
Innovation features (AI, scoring, QR, etc.) are ADDITIVE. They must never compromise the core.

## FIXED TECH STACK (do not substitute)
- Language: JavaScript (ES modules), Node.js LTS
- Frontend: React (Vite), React Router, Redux Toolkit (slices + createAsyncThunk), Axios,
  Tailwind CSS, FullCalendar, React Hook Form
- Backend: Node.js, Express, MongoDB, Mongoose, JWT (access + refresh in httpOnly cookies), bcrypt,
  Multer + Cloudinary (uploads), Zod (validation), node-cron (scheduled jobs), Socket.IO (real-time availability),
  Nodemailer (dev: console/Ethereal), Helmet, CORS, express-rate-limit
- Payments: simulated (deposit hold/release/refund recorded in DB); no external gateway
- AI (Phases 3–4 only): pluggable provider interface with rule-based fallbacks; app must fully work with no AI key
- Tools: Git/GitHub, Postman, VS Code, npm, MongoDB Compass. Docker is optional.
